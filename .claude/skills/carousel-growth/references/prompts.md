# Шаблоны для carousel-growth

Подставляй `{product}`, `{audience}`, `{pain}` из `carousel-growth/context.md`.

## Хуки (слайд 1)

Проверяй каждый хук: одна мысль, читается за секунду, обещает конкретную пользу.

- «{N} вещей, которые {audience} делают неправильно с {topic}»
- «Как я {результат} за {срок}, не {неприятное действие}»
- «Показываю, как {продукт} решает {pain} за 15 секунд»
- «Сохрани, чтобы не потерять: {полезный список}»
- «То, что мне не говорили про {topic}»
- «До / после: {результат}»

Библиотеку хуков наполняй реальными постами из `trends.md`, а не этим списком.
Обновляй раз в две недели.

## Трендвотч: промпт для агента

```
Контекст продукта: {context.md}.
Найди 20 недавних каруселей/видео в нише на аккаунтах 10k–250k подписчиков.
Для каждого: ссылка, формат, хук, просмотры, подписчики, save rate (если доступен),
сложность производства (1–5) и 2 самых залайканных комментария.
Отбрось всё со сложностью >3. Верни 10 идей с референсами и предложи 2 варианта
месседжа на каждую.
```

## Карусель: промпт для генерации слайдов

```
Персонаж: {character.md}. Идея: {идея}. Хук: {хук}.
Сделай {N} слайдов 4:5 (или 9:16 для TikTok). Верх и низ оставь свободными
под интерфейс (safe zones: ~12% сверху, ~20% снизу, ~10% справа).
Изображение без текста; текст добавляется отдельным слоем.
Сохраняй лицо, возраст, причёску и стиль одежды из референса.
Последний слайд: демо продукта (скриншот) + CTA.
```

## Недельный отчёт

```
Метрики за неделю: {экспорт}.
Таблица по формату/хуку/персонажу: просмотры, save rate, переходы, установки,
покупки, покупок на 1k просмотров. Выдели победителей и аутсайдеров, объясни
почему (по правилам из шага 4) и предложи 3 эксперимента на следующую неделю.
```
