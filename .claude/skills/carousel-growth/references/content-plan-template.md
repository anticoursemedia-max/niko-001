# Контент-план каруселей на 2 недели (шаблон)

Заполни `{...}` из `carousel-growth/context.md` и `trends.md`. План рассчитан на **один
аккаунт**; для нескольких аккаунтов копируй колонки и меняй хуки и внешности, а не
повторяй те же посты.

## Логика

- **Неделя 1 — исследование.** 5 постов, каждый проверяет другую гипотезу (формат, хук, внешность). Цель: найти 1–2 сигнала.
- **Неделя 2 — итерация.** 5 постов: 3 вариации победителей недели 1 (другой хук, внешность или CTA), 2 новые гипотезы.
- **Не масштабируем до разбора.** Решение о видео, инфлюенсерах и paid — только после точки проверки дня 14.
- Один пост = одна проверяемая гипотеза. Не меняй в одном посте сразу формат, хук и персонажа.

## Подготовка (до дня 1)

- [ ] `context.md` заполнен (продукт, аудитория, CTA, площадки)
- [ ] `trends.md`: 10 идей с референсами, выбрано 8–10 для плана
- [ ] Персонаж и набор обложек готовы, лицо проверено глазами
- [ ] Аккаунт прогрет, аналитика настроена (вопрос «как узнали», UTM)
- [ ] 2–3 карусели показаны пользователю и одобрены

## Структура одной карусели

1. Слайд 1 — хук (одна мысль, читается за секунду)
2. Слайды 2–{N-1} — ценность или история
3. Слайд {N} — демо продукта + CTA

Текст накладывай отдельным слоем; учитывай safe zones площадки.

## Точка проверки 1 (воскресенье недели 1)

Для каждого поста запиши через 48–72 часа после публикации:

| Пост | Просмотры | Save rate | Переходы | Установки | Покупки |
|---|---|---|---|---|---|
| | | | | | |

Решения:
- save rate выше медианы → идёт в план недели 2 как «победитель»;
- много просмотров, мало сохранений → меняем месседж/CTA;
- нет сигнала → меняем гипотезу, а не количество постов.

## Точка проверки 2 (воскресенье недели 2)

- Сколько покупок на 1k просмотров? Сравни со своим уровнем (у Нади в Aesty ~1 покупка на 4–6k просмотров — это ориентир, не норма).
- Есть ли формат, который повторяется как победитель в 2+ постах? → следующий слой (видео по победителям, инфлюенсеры).
- Нет сигнала за 2 недели при нормальном объёме → пересмотри нишу, формат или персонажа, и вернись к шагу 1 скилла.
- Запиши выводы в `carousel-growth/learnings.md`.
