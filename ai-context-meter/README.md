# AI Context Meter (Windows)

Маленькое окно поверх всех окон с полосками заполнения контекста.

## Запуск
1. Установите Python 3.9+ (с tkinter, галочка "tcl/tk" в установщике).
2. `pythonw meter.py` (без консоли) или `python meter.py`.
3. Перетаскивание — ЛКМ, выход — ПКМ → Exit. Позиция и настройки: `%USERPROFILE%\.ai_context_meter.json`.
4. Автозапуск: положите ярлык на `pythonw.exe meter.py` в `shell:startup`.

## Источники
- **Claude Code** — точные данные: читаются токены последнего ответа из `%USERPROFILE%\.claude\projects\*\*.jsonl`. Для 1M-контекста поставьте `claude_code_window: 1000000` в конфиге.
- **Claude.ai / ChatGPT (веб)** — только оценка (~3.5 символа на токен по тексту страницы): поставьте `claude_web_userscript.js` в Tampermonkey. Скрипт шлёт данные на `127.0.0.1:8765`. Лимиты окна (200k / 128k) правьте в начале скрипта.

Ограничения: у веб-версий нет официального API контекста, процент приблизительный; селектор `main` может измениться после обновления сайтов.
